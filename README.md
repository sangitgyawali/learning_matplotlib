## 🌟 Introduction to Matplotlib

Matplotlib is a powerful Python library for **2D plotting**.  
With it, I have learned how to:  
- Create **simple plots** to visualize data  
- Understand the structure of **figure & axes**  
- Use **Matplotlib functions** for plot customization  

💡 Tip: Every plot in Matplotlib is a **figure containing axes**, which allows for flexible plotting layouts.

---

## 📂 Plot Functions

### Line Plots
- Visualize trends over **time or ordered data**  
- Customize **line style, width, and color**  

### Scatter Plots
- Explore **relationships between two variables**  
- Adjust **marker size, shape, and color** for clarity  

### Customization
- Add **titles, labels, and legends**  
- Change **colors and markers** to make plots more readable  
- Control **figure size** for reports or presentations  

---

## 📂 Multiple Charts

- Create **multiple plots in a single figure** using `subplot`  
- Use **pie charts** to show category proportions  
- Use **histograms** to understand **data distributions**  

💡 Tip: Multiple charts in one figure help **compare data easily** without switching between plots.

---

## 📂 Saving Figures

- Save plots as **PNG** using `plt.savefig()`  
- Adjust **figure size** and **dpi** for high-quality exports  
- Useful for including plots in **reports, presentations, or blogs**  

---
