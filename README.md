# 🎬 Netflix Data Visualization

This repository contains my hands-on practice of **data visualization** using **Matplotlib** with Netflix-related datasets.  
It’s part of my **Month 2** learning journey in the 6-month Data Science & AI/ML roadmap.

---

## 📚 Topics Covered

### 📂 Introduction to Matplotlib
- Basics of creating simple plots
- Understanding figure & axes

### 📂 Plot Functions
- Line plots
- Scatter plots
- Customizing colors, markers, and labels

### 📂 Multiple Charts
- Creating multiple plots in a single figure
- Pie charts
- Histograms

### 📂 Saving Figures
- Exporting plots as PNG (`savefig`)
- Managing figure size & resolution

## 📊 Why Data Visualization?

Data visualization helps transform **raw numbers into meaningful insights**.  
With Matplotlib, I can:
- Explore data distributions  
- Compare categories  
- Identify patterns & trends  
- Communicate results effectively
